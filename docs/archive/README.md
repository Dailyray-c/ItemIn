# 历史归档（archive）

> **本目录下的一切都不是开发依据**，只用于追溯「当时为什么这么决定」。

## 规则

1. 文档一旦被取代、或描述的版本已不可达 → **移到这里**，不要留在 `docs/` 根下与现行文档并存。
2. 每个文件顶部有统一横幅，说明归档时间与替代文档。
3. 归档文件**不再维护**：里面的版本号、行号、功能清单都可能与代码不符，**不要据此判断当前行为**。
4. 需要引用其中的结论时，先到现行文档确认该结论是否仍然成立。
