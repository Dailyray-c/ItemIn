## 4. Tailwind 编译与「漏编译」陷阱

- 新增任何从未出现过的 utility → 立即 `npm run build:css`
- **未编译 = 样式失效但功能正常**。诊断顺序：`getComputedStyle(el).backgroundColor` → 再量 `getBoundingClientRect().height` / `offsetParent`
- ❗**JS 事件正常但点不到 → 先量高度是否塌陷为 0**，别查 JS
- 任意值类在 CSS 里是转义形式（`text-[11px]` → `.text-\[11px\]`）
- 校验类是否存在用 `grep -o`，**不要**用 `grep -c`（minified 只有一行，恒为 1）

## 5. Vue 单文件隐藏 Bug 模式

1. ❗**漏进 `return {}`**：模板里 `settings.x = v; saveData()` —— 赋值在抛错前执行，UI 看着正常，
   真实后果只有「不落盘 / 刷新回滚 / 无 toast」
1b. ❗**漏进 `return {}` 的第二副面孔（更显性）**：如果漏的是**处理器本身**（`@click="toggleCategory(...)"`），
   那么一句话都不执行 → `TypeError: toggleCategory is not a function`，控制台每点一次报一次，按钮完全是死的。
   v1.4.0 前就漏了 `toggleCategory`（录入 / 批量录入 / 编辑三处「分类」按钮全废），排查成本高是因为
   **页面不报错、只有点击时炸**。判定只需一条：`模板里被调用的名字 ⊆ return{} 键集`。
   自查姿势：取模板区 `{{ }}` 与 `:x=` / `@x=` 值里的 `name(`，减去 setup 里 `function name` / `const name =`，
   差集非空即有雷（本次从 94 个调用点里揪出 1 个）。
2. ❗**无参事件处理器把 DOM Event 当实参**：`@change="fn"` → 第一个实参是 Event，带默认值的形参静默失效。
   修复 = 补实参 **+** 处理器内加形态护栏（如 `'productionDate' in item`）
3. ❗**同文件多 Edit 必须串行**：同一消息并发多个 Edit 只有 1 个生效
4. `window.__itemin` 是**手写枚举**（≠ `return {}`）；ref 要 `.value`，getter 要 `()`，setter 用 `setXxx()`
5. 新全局组件必须 `app.component()` 注册；每个 `createApp({` 配 `});`

## 6. 数据与同步陷阱

- ❗**`DEMO_MARK` 示例数据必须对同步引擎完全不可见**：
  - `captureState()` 过滤 demo；
  - `applyStockDelta()` 对 demo 商品直接 `return`（delta 是绕过分差的独立通道，必须**单独拦**）
- **幽灵商品**：`quantity <= 0` 必是脏数据（正常归零走 `removeProduct`）。兜底 `purgeGhostProducts()`
- **位置 chips 顺序**：一律遍历 `placesOrderedView`，固定「待设置 → 有分区 → 无分区」
- ❗**chip 组顺序 = 设置列表权威**：`unionTags()` 先按设置列表铺满、遗留标签追加末尾；
  **禁把「当前已选」先塞进去**（`Set` 保插入序 → 每点一次就重排）
- ❗**chip 禁悬停变色**：芯片只有选中/未选中两态
- **撤销**：快照存 `itemin_undo_cache`（上限 300 / TTL 60 天），**不进云**；
  `adjust` 只回填本条改过的字段；**数量一律走 delta 反向**，不用快照绝对值
- **保质期是文本**（`"12个月"` / `"2年"` / `"90天"`，历史纯数字按「天」）；
  三个入口 `splitShelfLifeValue` / `composeShelfLifeText` / `setShelfLifeFromText`；
  ❗禁把整条文本塞进 `type=number`
- **`_slTouched` 挡无操作重写**：保存时无条件重算会把 `"364"` → `"364天"` 并凭空生成调整记录
- **`settings.locations` 已废弃**，唯一真源是 `settings.places`
- **`SETTINGS_SYNC_SCHEMA` 驱动云同步设置**：新增同步字段只加一行；
  `localFirst` 表示本机值合法就保留并回推云端
- **本机专属不进 schema**：`simpleMode` / `tourDone` / `demoKept` / 云密钥 / 撤销快照

## 7. Playwright 套路

- 用 PowerShell 调托管 node；`require('playwright')` 从项目 `node_modules` 取
- 服务端口 **8777**、地址必须 `localhost`
- 脚本必须 `try/catch + flush`
- 读页面状态用 `__itemin.currentPage.value`
- 预置 localStorage 键无 `_v1` 后缀；写错 → 空库 → 触发首次导览
- ❗**导览遮罩拦点击**：先等 ~1500ms 让导览起来，再 `endTour()`，并确保 `tourDone = true`
- ❗`fill()` 对 number input 不派发 `change` → 补 `.blur()`

## 8. 性能 / 首屏

- 扫码库（375KB）与二维码库（20KB）不在 `<head>`，由 `ensureScanLib` / `ensureQrLib` 按需注入
- ❗预取必须先 `setTimeout(..., 2500)` 让位，再 `requestIdleCallback`，否则与首屏/云同步抢带宽
- ❗验证「首屏体积」要在 `#app` 首次可见那一刻快照 `performance.getEntriesByType('resource')`，
  晚一点预取已跑完，会测出优化前的假象
- 导览启动：`document.fonts.ready` → 双 rAF → 240ms 稳定期（固定延时在慢机会量错高亮框）

## 9. Service Worker

- 白名单模式：只接管**同源 GET**；跨域与非 GET 一律放行、永不缓存
- 导航网络优先；静态资源 cache-first + 后台 revalidate
- 预缓存用 `Promise.allSettled` 逐资源（替代 `addAll` 全有全无），失败点名日志
- 静态资源回源失败返回 **504**，**不伪造首页 HTML**（否则 `<script>` 拿到 HTML，报 `Unexpected token '<'`）
- `activate` 只清自身前缀 `item-inventory-` 的旧缓存
- ❗改 `index.html` / `styles.css` / `service-worker.js` / `vendor/` → **必须 bump `CACHE_NAME`**

## 10. 发布与 Git

- **发布命令**：`./push-safe.sh "说明"`；**严禁 `git add .` / `-A`**
- 新增 `docs/` 文件不在 `push-safe.sh` 白名单 → 走 `push-clean.sh` 或手动 `git add docs/`
- ❗**push 假成功**：代理可能返回空 502 被当成 200。判活用 `git ls-remote origin <branch>` 比对 OID
- `git fetch origin master` 只写 `FETCH_HEAD`，不建远程跟踪引用 → 用 `git rev-parse -q --verify FETCH_HEAD` 取 OID
- ❌ **绝不 `git stash` + `git rebase`**（曾被 SIGTERM 打断导致 `.git` 损坏）
- ✅ 安全流程：`fetch` → `reset --mixed`（不碰工作树）→ `add <明确文件>` → `commit` → `push`
- `.git` 损坏的标准修复：删 `.git` → `git init` → `add remote` → `fetch` → `reset --mixed`（**工作树不丢**）

## 13. 排错速查表（现象 → 优先检查）

| 现象 | 优先检查 |
|---|---|
| 按钮看不见 / 点不到，但 JS 正常 | Tailwind **漏编译** → 量 `getBoundingClientRect().height` 是否 0 |
| 改了设置刷新就回滚 / 无 toast | 函数或状态**漏进 `return {}`** |
| 点按钮控制台报 `xxx is not a function`，按钮像死的 | 该**处理器本身漏进 `return {}`**（模板调用了、setup 有定义、但没登记） |
| 某种操作顺序下联动不执行 | 模板 `@change` **无参**，Event 被当实参 |
| 选中/取消标签后整行顺序乱跳 | `unionTags()` 把「当前已选」先塞进去了 |
| 家人手机看到演示商品 | `__demo__` 被纳入云同步 → `captureState` / `applyStockDelta` 漏拦 |
| 首屏优化「测不出来」 | 空闲预取已跑完，验证时机太晚 |
| push 显示成功但线上没更新 | 代理假 200 → `git ls-remote` 比对 OID |
| 回归脚本无输出 / 退出码 23 | 用 PowerShell 调托管 node；脚本缺 `try/catch + flush` |
| 导览遮罩拦住所有点击 | 未 `endTour()` / 未等 1500ms / `tourDone` 非 true |
| 页面样式是旧的、HTML 是新的 | `?v=` 未变或 SW 缓存未失效 → Clear site data |
| `data-page-node-id` 相关报错 | IDE 注入属性污染 HTML → 写入后 strip 再验 pageerror |
| 商品位置筛选不到 | `location` 存了数组 / 未归一化 → 走 `normalizeProductList` |
