① 首页 · 库存总览
一眼看清家里有什么、什么快过期了
  • 顶部四卡：在库 / 待补货 / 借出未还 / 需关注，点卡片即筛选
  • 卡片四按钮：+1 入库 / −1 取出 / 借出 / 编辑；点右上数量可直接改总数
  • 通配符搜索：#分类 @位置 ?空价格 &正常
  • 到期越近越靠前，颜色随临期自动加深
  • 智能视图：待补货 / 借出未还 / 待归位 / 长期未动，一键筛
  • 借出 / 归还：点卡片「借出」记下借给谁，还回来点「归还」加回库存
  • 铃铛随时看临期 / 过期清单
首页：顶部四卡 · 智能视图 · 通配符搜索 · 卡片四按钮
  • 顶部四卡：在库 / 待补货 / 借出未还 / 需关注——「在库」回到全部，「待补货」按补货线筛，「借出未还」筛选并展开未归还清单（不弹窗），「需关注」筛临期 + 过期。三者互斥，同一时刻只选中一个；选中后列表上方会有对应的状态标记，没数据时标记下方会说明原因。
  • 搜索框（全字段）：输入关键词即匹配 名称/条码/位置/分类/品牌/规格/净含量/厂商/价格；支持 token 通配符——#分类 筛某分类、@位置 筛某储存位置、#待设置/@待设置 筛未设置分类/位置的商品、?空价格/?空净含量 筛对应字段为空的商品、&正常/&临期/&过期 筛对应状态商品；空格分隔可叠加（如 #日用品 @储物柜 &正常）。筛选弹层按钮会自动把通配符填进搜索框。
  • 筛选弹层：点「筛选」按 状态/分类/位置 组合过滤、排序、设日期范围；弹层按钮会自动把通配符填进搜索框。
  • 扫码搜索：点搜索框右侧相机图标可扫码定位某条码商品。
  • 商品卡：名称 + 位置/分类标签（未选显示灰色「待设置」），右上圆形为数量（可点，直接改总数），下方四个操作按钮。
  • 状态色：左边条与到期文字随临期变化——新鲜绿 / 临期橙 / 过期红（与主色同源的自有语义色，不再用 Tailwind 出厂色）。
  • 四按钮：+1 入库 / −1 取出 / 借出 / 编辑。右上角数量圆可点，直接改总数。
  • 取出最后 1 件会弹确认防误触；确为浪费（变质/过期等）请走 编辑 → 删除 →「浪费删除」，点选原因后计入浪费复盘。
  • 到期提醒：首页右上角铃铛随时看临期 / 过期清单，出现红点即有物品到期，点开优先处理，避免放坏或错过保修 / 归还日期。
  • 数量增减：首页卡片用 +1 / −1 每点一件；也可点右上角数量圆直接改成任意总数（两者都会留一条流水，可撤销）。编辑弹窗里只改属性，不改数量。
  • 默认排序：列表按临期排序，越接近到期的越靠前，先处理快到期的，减少浪费。
② 扫码 · 录入新商品
扫条码自动识别，三步完成入库 · 也支持批量录入
  • 扫码或手输条码，自动带出名称与规格
  • 三级回退：GS1 → 通用 → 进口
  • 分类与位置可多选，不选即「待设置」
  • 日期三联动（选填）：填两项自动算出第三项，三项都可留空
  • 批量录入：一次可录多件
扫码页：批量录入 · 分类/位置多选
  • 扫条形码：条形码位于「基础信息」卡第一项——点输入框右侧相机图标扫码，或手动输入条码后点「查询」。
  • 三级回退：GS1 官方库 → 通用商品库 → 进口商品库，自动填充名称/品牌/规格/净含量/厂家/图片。
  • 缓存更新：查过的码显示「更新」，再点一次强制走 API 刷新为最新数据。
  • 分类 / 位置多选：一个商品可同时勾选多个分类与多个位置——例如录入「抽纸」，分类勾选 日用品 + 清洁用品，位置勾选 储物柜。都不选 =「待设置」，以后可在首页/编辑里补。录入页与主页编辑弹窗均为芯片多选（v2.21.14 对齐）。
  • 日期信息（选填）：默认收起，点标题才展开——先选到期类型（保质期 / 保修 / 更换 / 归还，默认「保质期」），再填生产日期 / 保质期（日·月·年 可切换）/ 到期日期，三项都可留空；任填两项第三项自动算出。保质期默认按 日 计，需要月 / 年时手动切一下单位。同一套日期字段服务所有物品：食品看保质，电器看保修，耗材看更换。
  • 总价 / 初始数量：总价为本件商品价格，初始数量为本批入库件数。二者分清，统计才准。（净含量已移入「更多信息」）
  • 更多信息（折叠）：品牌、生产厂家、规格、净含量（单件商品）、商品图片、入库日期（自动锁定，批量录入另有备注），可扫码自动带出。
  • 填好点 提交入库 即完成（商品名称必填）。
  • 批量录入：扫码页顶部另有「批量录入」入口——一次录入多件商品；点「+ 添加商品」逐条补录，改完直接「保存全部」一次性批量入库（入库记录标记「批量入库」）。
  • 前置条件：需在设置里开启「条码查询增强」才能自动识别商品信息；不开启也可手动填写。
  • 查不到时：三级回退都查不到时，仍可手动填名称 / 品牌继续入库，不影响后续统计。
  • 商品照片：「更多信息」折叠区可贴商品照片，下次同码扫码会自动带出，省得重填。
  • 保存全部：一次性写入多件商品，且每件都会生成一条「批量入库」记录，可进入「记录」页查看。
  • 入库后的云同步：录入页与批量录入页的顶栏也有云同步按钮（与首页同一个），录完不用退回首页就能确认数据上云。数据改动后 15 秒会自动同步一次，按钮会显示当前状态——同步中（靛蓝转圈） → 已同步到云端（绿色） → 同步失败（红色，常驻到下次成功）；点一下按钮即可手动立即同步。详见「设置」模块的云端数据同步。
③ 记录 · 操作历史
所有入库 / 取出 / 浪费 / 调整一目了然，还能撤销
  • 四个快捷筛选：全部 / 入库 / 取出 / 浪费
  • 按今天 / 昨天 / 日期分组，每组显示条数
  • 高级筛选：记录类型 + 日期范围
  • 每条可撤销，退回操作前的状态
记录页：四筛选带件数 · 一键撤销回滚
  • 快捷筛选：顶部「全部 / 入库 / 取出 / 浪费」一键切换对应记录。
  • 搜索定位：搜索框全字段模糊匹配（商品名 / 条码 / 操作详情 / 类型），或点相机图标扫码定位某条码的所有记录。
  • 高级筛选：点「筛选」按 记录类型 + 日期范围 组合过滤（激活后按钮变橙并带圆点）。
  • 分组展示：记录按 今天 / 昨天 / 具体日期 分组，每组显示条数。
  • 记录内容：类型徽章（入库木纹棕 / 取出青绿 / 浪费红 / 借出天蓝 / 归还翠绿 / 调整灰）+ 商品名 + 数量 + 时间 + 备注。
  • 撤销：每条右侧「撤销」把这条操作退回操作前的状态，弹窗会先说清要还原什么再让你确认。入库按数量扣回；取出 / 浪费把商品完整恢复（位置、分类、各种日期、保质期、价格、备注一起回来），商品已被移出库存时也能整条还原；调整会把你编辑过的商品信息整体还原。撤销 ≠ 删除商品——商品仍留在库里。本机的撤销靠一份存在本机的「操作前快照」实现，所以只有你自己做过的操作能这样完整还原，别人的记录保持原样。
  • 浪费定位：高级筛选单独勾「浪费」，可快速定位家里总在丢什么，针对性少买。
④ 统计 · 趋势与金额
看清浪费在哪、钱花在哪，越用越省
  • 顶部时间范围一切换，所有指标联动
  • 库存资产（首屏）：库存货值 / 可用天数 / 在库 / 已过期
  • 近 6 月趋势：入库 / 取出 / 浪费三色对比
  • 浪费复盘：默认收起，记录时点选原因才统计得准
  • 甜甜圈图例可点，跳首页按该标签筛选
  • 数据质量：点一下直达首页补全字段
统计页：库存资产 · 三色趋势 · 库存状态
  • 时间范围：顶部预设「今日 / 近一周 / 近一月 / 本年度」，或自定义起止日期；所有指标随范围联动。
  • 库存资产（首屏）：库存货值、可用天数、在库件数、已过期件数——先回答「家里值多少钱 / 还能用多久」。其中可用天数 = 当前在库件数 ÷ 近 30 天日均流出件数，随「取出 / 浪费」记录积累越来越准；刚使用时因日均流出基数小，数值参考意义有限。本卡不随时间范围变化。
  • 浪费 · 复盘（默认收起）：只在真产生过浪费时才出现，点标题才展开——含浪费率 / 浪费金额 / 浪费净含量，以及按浪费原因（放过期了 / 变质了 / 用不上了 / 买多了 / 其他）按月复盘的件数与金额，其中过期 / 变质 / 买多合计为「可避免浪费」。记得浪费时点选原因，复盘才准。
  • 近 6 月趋势：入库 / 取出 / 浪费 三色柱状对比（红柱为浪费），柱顶为单月件数，可发现囤货与短缺规律。
  • 当期金额：采购金额与取出金额大字并排展示，附日均金额与累计件数，底部为净支出（采购 − 取出）。
  • 库存状态：甜甜圈展示正常 / 临期 / 过期占比，中心为总件数与临期占比；点击状态标签可跳到首页按该状态筛选。
  • 分类 / 位置分布：两个甜甜圈展示分类与储存位置占比；点击图例可跳到首页按标签或位置筛选。
  • 数据质量：「价格待设置」「净含量待设置」以及标签 / 位置待设置的数量，点击可跳到首页补全对应字段。
  • 浪费金额口径：浪费金额 / 净含量按记录时快照的单价统计，单价从使用后自动积累，越用越准。
  • 范围联动：切换时间范围后所有数字联动，对比「近一周」与「本年度」能看出近期是否囤多了。
⑤ 设置 · 个性化与同步
调好这些，物品记 才真正顺手
  • 临期判定天数决定首页与铃铛的提醒范围
  • 存储位置 / 分类都在这里增删改
  • 云同步：填 Upstash REST URL + Token，或扫码接入
  • 导出备份：CSV 表格 / JSON 存档
  • 安装到主屏，像 App 一样打开
设置页：临期判定 · 位置分类 · 云同步
  • 使用指南 / 新手导览：设置页顶部入口，随时回看本指南；指南页顶部有「新手导览」、每个模块右上角有「实景体验」，都能重放一次带练。
  • 简洁模式 / 字号大小：一键开启简洁模式，只保留常用功能（开启时字号会同时设为「大」）；字号也可单独选「标准 / 大 / 超大」，点一下立即生效。
  • 即将到期判定：填「到期前 N 天」算临期（默认 7 天），决定首页 / 铃铛的临期提醒。
  • 存储位置列表：添加位置；编辑模式下可拖动排序、点名称重命名、点 × 删除（如 冰箱冷藏 / 冷冻 / 橱柜），顺序会同步到首页筛选与下拉。
  • 删除 / 重命名位置时商品会怎样：删除一个位置（含它下面的全部分区，如删「冰箱」会连「冷藏 / 冷冻」一起）时，用着这些位置的商品不会丢，只是位置被清空、显示为「待设置」，之后可按 @待设置 筛出来重新归类；重命名位置时，用它的商品会自动跟着改名，原有的分区（如「冷藏」）保持不变、显示为新名字加分区（如「冷柜 · 冷藏」）。两种情况都会弹出说明并列出受影响的商品，改动前心里有数。
  • 商品分类列表：同上管理分类（日用品/清洁用品/食品…）。
  • 云端数据同步：在 upstash.com 免费建一个 Redis 库，把 REST URL + REST Token 填进来即可开启；多设备按事件全序增量收敛（如妈妈 −1 + 爸爸 −2 = 云端 −3，互不覆盖），支持立即同步、自动保存间隔，断网恢复自动补同步。
  • 自动同步与状态指示灯：数据一有改动，15 秒后会自动同步一次（连续操作会合并，不会每改一下就发一次请求）；另外 App 启动、网络恢复、切回前台时也会自动补同步，失败后按 30 秒 → 1 分 → … 最长 5 分钟的间隔自动重试。这些自动同步的状态都显示在顶栏的云同步按钮上——靛蓝色 + 转圈 = 正在同步，绿色 + 「已同步到云端」= 刚刚同步成功（约 2.4 秒后恢复常态），红色 + 失败原因 = 同步失败（会一直留着，直到下次同步成功）。点按钮即手动同步，手动操作仍会弹明确的提示条。首页、录入页、批量录入页的顶栏都有这个按钮。
  • 安装到主屏（PWA）：手机浏览器「添加到主屏」即可像 App 一样打开，图标为购物篮；v2.18.2 起已优化启动图标显示，避免被系统裁切。
  • 条码查询增强：开关 + 可选 API Key，开启后扫码自动识别商品信息（三级回退）。
  • 导出表格（CSV）：库存 / 操作流水 / 统计 三种表格一键导出，Excel、WPS 直接打开；统计导出跟随当前统计页时间范围。
  • 名称清洗规则：录入时自动去营销词、统一大小写与全半角（可逐项开关、自定义词库、白名单保护），也支持一键「整理历史名称」先预览再应用。
  • 扫码配置同步：换新设备不用手抄长串 Token——老设备「生成配置码」、新设备「扫码接入」即共用同一云端数据库（配置码含密钥，仅当面使用、30 秒自动关闭；本机数据先并入云端，不会被覆盖）。
  • 导出 / 导入 / 清空：导出 JSON 备份；导入合并不覆盖新数据；清空全部数据⚠ 慎用（开云同步会同步清空所有设备）。
  • 版本：底部点版本号查看更新日志。
  • 备份建议：导出 JSON 建议每月一次；换手机或重装前务必先导出，随时可「导入」恢复（导入为合并不覆盖）。
